# Contributing to Invidious React Client

Thank you for contributing! This repository uses React, TypeScript, Vite, Electron, and Capacitor.

## Getting Started

1. Fork the repository and create a feature branch.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## Branching and Pull Requests

- Create feature branches from `main`.
- Keep PRs focused and describe the intent clearly.
- Reference any related issue number in the PR description.
- Include testing steps and affected areas.

## Coding Guidelines

- Use TypeScript for all new code.
- Keep React hooks consistent and follow hook rules.
- Run formatting tools and lint checks before submitting:
  ```bash
  npm run lint
  npm test
  ```

## Commit Messages

- Use clear, concise commit messages.
- Prefer present-tense descriptions.
- Group related changes logically.

## Testing

- Add or update tests when fixing bugs or adding features.
- Verify that existing tests continue to pass.
- Use `npm test` to run the test suite.

## Issues

- Open issues for bugs, enhancements, and questions.
- Provide steps to reproduce and expected behavior.
- Attach logs or screenshots when helpful.

## Security

If you discover a security vulnerability, please use the repository security policy rather than opening a public issue.
