# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this repository, please report it privately via GitHub Security Advisories for this repository. Do not create a public issue for vulnerabilities until a fix has been released.

## Supported Versions

This repository is maintained for the current default branch. Security fixes are accepted for the currently shipped version and the `main` development branch.

## What to Include

When reporting a vulnerability, include:
- a clear summary of the issue
- affected components or files
- steps to reproduce
- any sample code or payloads that demonstrate the issue

## Response Process

The maintainers will review and triage reported issues promptly. If a fix is required, it will be submitted as a secure update or patch as soon as possible.
